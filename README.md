# Notes app: Spring Security starter

Starter project for the Spring Security exercises. Spring Boot serves both the API and the frontend (`src/main/resources/static`). 
H2 database in memory.

## Run

```bash
./mvnw spring-boot:run
```

Open http://localhost:8080.

## Users

| Username | Password | Role |
| `user1` | `pw` | USER |
| `user2` | `pw` | USER |
| `admin` | `pw` | ADMIN |
