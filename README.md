# Notes app: Spring Security starter

Starter project for the Spring Security exercises. Spring Boot serves both the API and the frontend (`src/main/resources/static`). The H2 database is in memory and resets on restart.

## Run

```bash
./mvnw spring-boot:run
```

Open http://localhost:8080.

## Users

|---|---|---|
| `user1` | `pw` | USER |
